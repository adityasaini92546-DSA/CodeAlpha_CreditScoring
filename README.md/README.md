# Credit Scoring Model

## 📌 Project Overview
This project predicts whether a customer is creditworthy based on financial information such as income, debts, and payment history.

## 🛠 Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## 📂 Dataset Features
- Income
- Debts
- Payment History
- Creditworthiness

## 🤖 Machine Learning Algorithm
- Logistic Regression

## 📊 Model Performance
- Accuracy: 75%

## ▶️ How to Run

```bash
python train_model/train_model.py
```

## 📁 Output
- Classification Report
- Accuracy Score
- Saved Model (`credit_scoring_model.pkl`)
