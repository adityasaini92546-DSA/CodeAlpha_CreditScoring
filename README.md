# 💳 Credit Scoring Model using Machine Learning

A Machine Learning project developed using **Logistic Regression** to predict whether a customer is creditworthy based on financial information.

---

## 📌 Project Overview

The Credit Scoring Model predicts whether a loan applicant is likely to repay a loan or become a credit risk. Banks and financial institutions use similar models to make loan approval decisions.

This project uses customer-related features such as income, debt, payment history, and age to classify applicants into creditworthy or non-creditworthy categories.

---

## 🎯 Features

- Predicts customer creditworthiness
- Binary Classification using Logistic Regression
- Easy-to-understand implementation
- High prediction accuracy
- Model saved for future predictions
